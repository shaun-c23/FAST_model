Single-layer (FAST):
This model can only be run for surface melting and up to 6 active beam paths. Please see readMe-inputfiles.txt within the single_layer folder for more info on the input files to run the model.

More info about the FAST model here: 10.1016/j.addma.2024.104139

Multi-layer (FASTer):
This model extends FAST for multi-layer builds to simulation PBF processes. Powder properties are not considered unless complex boundary conditions are implemented through additional heat sources. Please see readMe-inputfiles.txt within the multi_layer folder for more info on the input files to run the model.

More info about the FASTer model here: 10.1016/j.apm.2025.116690
